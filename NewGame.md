# Cat Mafia — Game Design Document

База: копируем `third_party/web-sdk/apps/daloniil_test` → **`apps/cat_mafia`**.  
Исходный `daloniil_test` не меняем.  
Название: **Cat Mafia**.  
Тема: гангстерский кот / револьвер / мишени (маскот — оранжевый кот в федоре с револьвером).  
Для револьвера, мишеней и гангстер-кота в прототипе — **обязательные заглушки** (CSS/HTML), финальный арт подменим позже.

---

## 1. Flow запуска

### 1.1 Загрузка (новый этап)

- Загрузка ассетов происходит **на экране логотипа**, не на карточках.
- На логотипе есть **progress bar**, чтобы не казалось, что слот завис.
- Карточки появляются **только после** завершения загрузки.

### 1.2 Карточки

- Как в текущем слоте (инфо-карточки фич).
- **Без ожидания загрузки** — сразу **Click to Play**.

### 1.3 Вход в игру

- После клика — переход на доску (аналог текущего cloud/entrance flow, при необходимости адаптируем под новую тему).

---

## 2. Layout и UI

### 2.1 Доска

- **5 столбцов × 4 ряда** (горизонтальная доска).
- Нужна, чтобы снизу оставалось место под маскота.
- Paylines: обрезаем текущие 25 линий под 4 ряда (или **~20 линий**). Главное для прототипа — чтобы lines работали; финальный набор можно позже.

### 2.2 Маскот

- Гангстерский кот стоит **от нижнего правого угла до доски**.
- Всегда на экране в основной игре и бонуске.

**Анимации маскота (минимум):**
| Анимация | Когда |
|---|---|
| Idle | Ожидание / обычный спин без ярких событий |
| Reaction / Wow | Крупные события: лапа→монетки, супер-вайлд, бигвин и т.п. |
| Clap | Позитивная реакция на хороший выигрыш |
| Load bullet | Патрон летит с доски → кот заряжает барабан (бонуска) |
| Aim & shoot | Финальный раунд мишеней: одной лапой закрывает глаз, другой целится и стреляет |

### 2.3 Кнопки / HUD

- Расположение кнопок **как сейчас** (spin, bet, auto, menu, buy bonus и т.д.).
- **Убрать** переключатель Bonus Boost с основной панели.
- Boost (ставка ×2) остаётся в:
  - **Autoplay**
  - **Buy Bonus меню**

### 2.4 Progress UI в бонуске

- Вместо текущей Progress Ladder — **барабан револьвера** (сверху / рядом с доской).
- Максимум **6 патронов**.
- Патроны визуально доставляются в барабан синхронно с анимацией кота.
- Старт бонуски: барабан **пустой** (0 патронов).

## 3. Базовая игра (Base Game)

### 3.1 Обычные символы

- Сохраняем логику дешёвых / дорогих символов (как paytable-группы).
- Обычный **Wild (`W`)** остаётся.
- Отдельный **Super Wild (`SW`)** — другой символ на рилах.
- Отдельный спецсимвол **Лапа (`P` / Paw)** — триггер превращения ряда в монетки.

### 3.2 Спецсимвол «Лапа» → превращение ряда в монетки

На рилы падает **не готовая монетка**, а спецсимвол **лапа**.  
Он превращает **весь ряд**, в котором упал, в монетки (символы на местах переворачиваются / заменяются на монеты).

| Исходный символ в ряду | Становится           | Выплата              |
| ---------------------- | -------------------- | -------------------- |
| Дешёвый (Low)          | Бронзовая монета ×1  | `1 × bet`            |
| Дорогой (High)         | Серебряная монета ×2 | `2 × bet`            |
| Wild                   | Золотая монета ×3    | `3 × bet`            |
| Scatter                | Золотая монета ×3    | `3 × bet` (как Wild) |
| Сама Лапа (`P`)        | —                    | **`0`** (не платит)  |

**Пример** (ставка = `$10`), ряд слева направо:

| Клетка | Было    | Стало     | Win     |
| ------ | ------- | --------- | ------- |
| 1      | Дешёвый | Монета ×1 | $10     |
| 2      | Лапа    | (лапа)    | $0      |
| 3      | Дорогой | Монета ×2 | $20     |
| 4      | Дешёвый | Монета ×1 | $10     |
| 5      | Wild    | Монета ×3 | $30     |
|        |         | **Итого** | **$70** |

**Поведение:**

1. Сначала отрабатывают **все остальные действия спина** (обычные выигрыши, Super Wild — если он на этом спине активен; см. взаимное исключение ниже).
2. Затем лапа активируется: ряд превращается в монетки (flip / replace на местах).
3. Монетки показывают свои ×1 / ×2 / ×3 и **складываются**.
4. Итог уходит в мешок/сундук WIN → merge в общий WIN спина.
5. Несколько лап в разных рядах — каждый ряд конвертируется отдельно; выплаты суммируются.

**Редкость:** лапа — редкий спецсимвол.  
**В бонусной игре лапа не падает** (вместо неё — патроны).

### 3.3 Взаимное исключение: Лапа XOR Super Wild

На **одном прокруте** может сработать **либо** механика Лапы, **либо** механика Super Wild — **не обе сразу**.

Это правило математики / book generation: в одном спине не бывает одновременной активации обеих фич.

### 3.4 Новый символ: Super Wild (Wild-штора с множителем)

- Отдельный символ от обычного Wild.
- Множители на символе: **×2 / ×4 / ×6 / ×8**.
- При активации раскрывается **шторой на весь столбец**, в котором упал.
- Весь столбец становится Wild.
- После пересчёта выигрышей сумма спина дополнительно умножается на множитель(и) Super Wild.
- Несколько открывшихся Super Wild на одном спине: множители **перемножаются** (`×2` и `×4` → `×8` к win спина).

**В базовой игре — условие открытия:**

- Super Wild раскрывается **только если сам символ участвовал в выигрышной комбинации**.
- Пример: линия задела клетку с Super Wild → триггер → штора открывается → столбец становится Wild → возможны новые выигрыши → итоговый win × multiplier.

**Если Super Wild не участвовал в выигрыше:**

- Не раскрывается.

### 3.5 Триггер бонуски

- **3+ scatter** на доске (в прототипе — текущий символ `B`/кот как плейсхолдер scatter).
- После триггера (натурального или buy) всегда идёт **сцена выбора мишеней** на количество FS.

## 4. Бонусная игра (Free Spins)

### 4.1 Два типа бонуса

|                      | Normal Bonus                                                                                         | Super Bonus                                                                  |
| -------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Buy cost             | **100×** bet                                                                                         | **200×** bet                                                                 |
| Сколько SW           | **Ровно один** на весь бонус                                                                         | **Ровно один** на весь бонус                                                 |
| Колонка SW           | **Любая** из 5                                                                                       | **Любая** из 5                                                               |
| Super Wild           | Лежит → открывается шторой → **sticky** на этой колонке до конца всех FS                             | С **первого** FS до последнего уже **открыт** на одной sticky-колонке        |
| Множитель Super Wild | Применяется к выигрышу спина                                                                         | Применяется к выигрышу спина                                                 |
| Лапа / монетки       | **Не падают**                                                                                        | **Не падают**                                                                |
| Патроны              | Падают вместо лапы, одинаковая редкость                                                              | То же                                                                        |
| Стартовые патроны    | **0**                                                                                                | **0**                                                                        |
| Мишени FS            | 8 / 10 / 12                                                                                          | 8 / 10 / 12                                                                  |

Отличие Normal vs Super — **только правило одного sticky Super Wild**.

На FS scatter (`B`) **не выпадает** — ретриггера бонуса нет.

В base на одном барабане (viewport + padding) — максимум **один** scatter.

В бонусе SW срабатывает **всегда** при появлении (без требования линии); в base — только если SW в выигрышной линии. SW может лежать на **любой из 5 колонок** (плотность по барабанам выровнена).

### 4.2 Выбор количества фриспинов (Buy и натуральный триггер)

- Количество FS **не фиксировано**.
- Значения за мишенями: **только 8 / 10 / 12**.
- Раскладка: **6 мишеней**, прямоугольная.

**Сцена выбора (и buy, и natural):**

1. Триггер бонуски / покупка Normal или Super.
2. На экране появляется поле из **6** больших мишеней.
3. Игрок тапает мишень.
4. Кот стреляет в выбранную мишень.
5. Мишень переворачивается → показывает число FS (8 / 10 / 12).
6. Остальные мишени тоже переворачиваются — игрок видит, что было за ними.
7. Результат **предопределён сервером/буком до клика**, UX создаёт ощущение выбора.

### 4.3 Накопление патронов

- В бонуске вместо лапы падают **патроны (bullets)**.
- Редкость ≈ как у лапы в base.
- Патрон летит **с доски в лапу кота** → кот заряжает **барабан револьвера**.
- Максимум в барабане: **6**. Больше 6 выпадать не должно (кап на математике/буке).

**Важно (жёсткое правило бонуски):**

- Патроны падают **только в основных фриспинах** (открытых мишенью на старте: 8 / 10 / 12).
- После финальной стрельбы, если игрок выбил **доп. FS** (`+1` / `+2` / `+3`):
  - на этих доп. FS символ патрона (**`BT`**) **не должен выпадать**;
  - `bulletCollect` на доп. FS **не эмитится**;
  - барабан **не пополняется**.
- Это правило обязательно и для **клиента**, и для **math / RGS books** (не только UI-флаг).

### 4.4 Финальный раунд: стрельба по мишеням

После окончания всех основных фриспинов:

1. Классическая доска символов уходит.
2. Появляется **доска мишеней** (красно-белые круги).
3. Игрок **ничего не нажимает**.
4. Кот целится и делает столько выстрелов, сколько патронов в барабане.
5. **Каждый патрон = гарантированный хит** в случайную ещё не подбитую мишень. Промахов нет.
6. За мишенью может быть только:
   - **пусто**;
   - **+FS**: `+1` / `+2` / `+3`.
7. Без денег / jackpot (на этапе прототипа).

**После +FS:**

- Доп. спины крутятся **без патронов** (см. §4.3 — `BT` не падает).
- **Второго shooting round нет** — только один раунд.

## 5. Порядок резолва спина

**Base game:**

1. Остановка рилов
2. Обычные выигрыши / реакции символов
3. **XOR-ветка A — Super Wild** (если на спине активен SW, а не лапа):  
   участие в win → штора → ре-eval → ×mult (multiply stack)
4. **XOR-ветка B — Лапа** (если на спине активна лапа, а не SW):  
   превращение ряда(ов) в монетки → сумма `bet×1/2/3` → мешок → merge WIN  
   _(лапа всегда после остальных действий спина)_
5. Реакции маскота по событиям
6. При 3+ scatter → переход к сцене выбора FS

**Bonus game:**

1. Остановка рилов
2. Выигрыши + логика Super Wild (normal/super правила)
3. Сбор патронов → анимация в барабан (только основные FS)
4. После последнего основного FS → shooting round → возможные +FS
5. Доп. FS (без патронов) → итог бонуски (без второго shooting)

## 9. Рабочие решения (сводка)

- Название: **Cat Mafia**, app: **`cat_mafia`**
- Загрузка с progress на логотипе → карточки → Click to Play
- Доска **5×4**, сначала desktop
- Маскот / револьвер / мишени — минимальные заглушки
- Boost тогл в **Autoplay** и **Buy Bonus** (не на основной панели)
- Base: **Лапа (`P`)** конвертит ряд: Low×1 / High×2 / Wild×3 / Scatter×3 / Лапа=0 — **после** остальных действий
- Super Wild mult: ×2/×4/×6/×8, stack = multiply; в base только если участвовал в выигрыше
- На одном спине: **Лапа XOR Super Wild**
- Триггер: 3+ scatter → сцена мишеней (и natural, и buy)
- Bonus: без лапы, вместо неё патроны; барабан max 6
- Bonus: только **один** SW; Normal — лежит → открывается → sticky; Super — открыт с 1-го FS на одной колонке
- Конец основных FS: авто-стрельба → пусто или +1/+2/+3 FS; один раунд
- На доп. FS после shoot патроны **не падают** (math + client)
- Math: mock → затем обязательный math-sdk
